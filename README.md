# 설비·홈케어 관리 (DB판 화면)

GitHub Pages로 공개되는 화면 파일입니다. 서버와 데이터는 Supabase에 있습니다.

- `index.html` 관리자 화면 — 접속 주소: `index.html?c=업체코드`
- `intake.html` 고객 정보 입력 화면 (관리자가 보낸 링크로 열림)
- `operator.html` 운영자 화면 (업체 추가·관리)
- `sw.js`, `push.js`, `manifest.json`, 아이콘 — 홈 화면 설치와 푸시 알림
- `config.js` 서버 주소

이 저장소에는 비밀번호나 비밀 키가 들어 있지 않습니다.
